# Workes.ConsoleSystem Project Notes

This folder contains lightweight project-management notes for `Workes.ConsoleSystem`.

The goal is to keep planning readable for humans while still being easy for Codex to scan and update.

## Documents

- [Board](BOARD.md): Trello-style project board with backlog, next work, active work, blocked items, and completed work.
- [Decisions](DECISIONS.md): Architecture and package-shape decisions that should remain visible over time.

## Update Guidelines

- Keep entries short and concrete.
- Prefer linking related decisions from board cards.
- Move cards between board columns instead of duplicating them.
- Record settled architecture choices in the decision log.
- Keep speculative ideas in the backlog until they are approved for design or implementation.
